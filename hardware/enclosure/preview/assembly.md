# V17三色灯原配支架安装

只修改顶盖；底壳、FPGA固定方式、主PCB、屏幕、小PCB、小模块、两个电脑线缆口位置均沿用V16。

安装位在屏幕右前侧、相机侧顶盖空白区，X75..125、Y-185..-55，50×130mm，顶面抬高2mm、局部厚9mm。原配一字支架长边沿机壳前后方向放置，支架大孔端朝前。四个7×18mm圆角槽中心X85/115、Y-140/-75，名义中心网格30×65mm；孔距从小尺寸截图读图估算并通过长槽留余量，非实测精密孔位。对于约4.3mm螺杆包络，中心矩形孔距的名义调节范围约横向27.3..32.7mm、纵向51.3..78.7mm（靠近圆角极限需核对；推荐围绕30×65居中装配），必须确认实际支架选用孔落入槽内。

1. 打开顶盖，在未装屏幕及线束时先安装金属支架。
2. 对准支架四个合适的小孔与顶盖四槽；建议4颗M4×20、4个M4螺母、8个外径至少12mm的大平垫圈。螺丝从上向下，顶盖内侧垫圈及螺母锁紧，先松装调整后交替轻锁。长度按实际支架厚度、垫圈和螺母叠层核对。
3. Ø32孔为支架大孔下方灯尾/螺母的空间避让，不是让灯直接夹在9mm厚塑料上。灯与原配金属支架用原配螺母/适配附件固定。
4. 报警灯采用支架固定，安装时按灯体法兰、尾部螺母和支架孔位配合垫片，保证线束出口与下方模块留有间隙。
5. 独立Ø8孔用于报警五线进入壳内。可加绝缘护线圈，实际可用线径按护线圈内径核对；在线内侧做固定，避免拉力传到端子。
6. 灯线在壳内接到J302及SW302原有接线，端子定义和极性沿用项目资料；开盖前先断电，给顶盖线束留维护余量或可拔插接头。
