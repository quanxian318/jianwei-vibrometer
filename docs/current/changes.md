# 最新集成变更（2026-11-04）

## 丢帧与帧率

- 同时修正代表波形分析和多点频谱窗口，允许丢帧率不超过5%、连续最多缺2帧；帧序号与时间戳必须一致，按每帧归一化检查10%时间间隔抖动。
- 分析时按时间戳插值到相机采样网格，保留原始波形、原始采样点数和丢帧计数；不生成或伪造摄像头图像。插值幅值为估计值，临近采样边界尤其应谨慎。
- 严重丢帧、跟踪失败、参考点失败仍拒绝。基线频谱窗口继续要求连续帧，避免把插值噪声训练为基线。
- fps_measured按帧序号跨度/时间计算相机采样率；新增fps_received记录实际收到的样本速率。UI实时指标命名为“接收帧率”，预览刷新率单独统计。
- 频率软件搜索上限30Hz，但受真实奈奎斯特边界约束；频谱图显示扩展至min(30Hz, fps/2)。45fps不能据此宣称测到30Hz。

## 报警一致性

- 实测复现：最新结果的频率有效而代表位移波形无效时，旧程序会保留上一次报警；修改阈值也不会立即重新判级。
- 统一按有效、已标定、有限且非负的代表测点峰峰值判定。二值模式严格“超过”阈值才报警，等于阈值不报警。
- 新结果无有效振幅时改为“未判级”，清除旧红/绿灯及蜂鸣器状态，不把无效值误当正常。频率与振幅有效性分开。
- 设置阈值后立即重新判断当前结果，实时UI/API与灯态同步；历史记录仍保留采集时的阈值及判级。
- 红黄绿灯和蜂鸣器一次掩码写入，读回输出及方向寄存器；失败重试，期望状态未变也每秒刷新。alarm_output_ok仅表示寄存器确认，不是实物灯电流反馈。
- 在记录保存/声学收尾前输出报警；静音只关闭蜂鸣器，不熄灭红灯。
- 多点结果页将“测点RMS”卡片改为报警所用的“峰峰值”，无有效振幅时显示--；接口返回null而非默认0。
