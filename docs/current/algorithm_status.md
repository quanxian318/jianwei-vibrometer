# 当前算法、分工与验证边界

## PL / PS / Nano分工

PL负责双路OV5640采集、3路VDMA/DDR/HDMI、PDM麦克风接收、补光PWM与看门狗、独立打印UART。PS/Linux负责模板跟踪、静止参考补偿、基线、频谱与位移统计、判警、UI/APP接口和记录打印。Nano负责SD卡语音、NFC与Wi-Fi网关。

复杂PL双目深度核已移除，保留PS辅助深度：160×90、5×5 census、两路径、64视差、约1Hz请求。

## 多点视觉测振

1. 1280×720、配置约45fps相机数据；测量框中最多12点（默认4×3），框外4个静止参考点。
2. 25×25局部模板、高斯平滑、梯度迭代和相关性检查获得亚像素位移；参考点共同平移用于去除相机整体抖动。
3. 128帧分析窗，检查有效性及时间基准。停机基线各窗口要求连续、覆盖全部测点，至少5个有效窗；每次程序启动或布局改变需重新采集基线。
4. 去趋势、Hann窗、FFT；保存各测点频谱最大包络作为基线。运行时比较相邻频点基线，3倍幅值比通过门限；通过窗口频率取中位数，并保存范围。
5. 代表测点输出单轴去趋势波形、峰峰值及RMS；多点核心另有二维图像平面谐波RMS，两者不能混作同一个报警指标。
6. 有界短缺帧仅在分析阶段重采样；限额与时间检查详见变更说明。跟踪/参考失败不被该容限掩盖。
7. 搜索0.5～30Hz，同时保留真实采样上限和奈奎斯特边界峰检查。

入口：src/measure/session.cpp、multipoint.cpp、spectrum.cpp，third_party/axvibration/portable_vibration.c、vb_runtime.c、spatial_core.c。

## 标定与报警

毫米换算采用与测量点同平面、方向一致的尺子标定。现有试验比例0.20308513971015377mm/px，机位、深度或测量方向改变后应重新核查。

默认源码有布局哈希检查；历史部署快照绕过该检查，沿用当前尺标比例。tools/reproduce_legacy_binary.py显式复现该行为。

报警使用有效代表波形的单轴峰峰值（mm）。有效性与当前阈值统一判级；无有效毫米振幅即“未判级”。报警灯和蜂鸣器按判级输出。

参考点布置在静止背景的清晰二维纹理区域，69 个基线窗口全部通过；测量阶段得到完整有效波形。

## 整机设备运行

整机设备已按设计完成联调。Nano UART 链路承担 NFC、SD 语音和网络网关的数据交互；NFC 与 microSD 共用 SPI，按各自片选完成读卡与文件访问。语音覆盖基线采集、测量、报警和打印等操作。

7 英寸触屏提供本机界面，前面板旋转编码器与按键执行界面操作，5 颗 WS2812 灯显示设备状态。SHT40 与 ToF 提供环境条件和距离辅助信息，声光报警灯、补光、十字激光、风扇和热敏打印机按功能流程工作。

记录中的 spectral_peak_mm 为代表测点波形独立频谱的峰值幅度，多点汇总主频由有效分析窗的频率中位数得到。报警使用代表测点选定方向的时域峰峰值。

## 报警模式

提交示例采用二态模式，峰峰值严格大于 alarm_peak_to_peak 时报警，其余有效结果为正常。三态模式分别使用大于等于报警阈值和大于等于预警阈值的条件。源码生成记录将 binary_threshold 与两个阈值一起保存。
