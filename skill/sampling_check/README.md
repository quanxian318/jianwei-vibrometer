# 采样与搜索范围检查

适用场景：视频、振动或其他等间隔采样信号出现“频谱有峰但算法无效”。
来源：约45fps采集下，21.6～22Hz峰值被旧0.45fs搜索上限排除；1320rpm的一倍转频约22Hz。
用法：`python check_sampling.py --fs 45 --target 22 --search-max 30`；可附`--legacy-ratio 0.45`核查旧上限。
输出：奈奎斯特频率、旧搜索上限、必要条件与接近边界提示。退出0仅代表通过本工具核查；目标不满足fs/2边界或超出搜索范围时退出2。
已验证：45/22/30通过且标记接近边界、原0.45fs会排除；45/30/30拒绝。自动自检另含无效输入。
边界：实际帧率须来自采样时间戳，不是界面刷新或相机标称帧率；不能用此结果排除混叠，也不能证明测点质量、幅值准确或毫米标定有效。
