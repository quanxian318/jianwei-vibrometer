# 交付包完整性检查

适用场景：复制、压缩、解压或上传工程前核对文件版本及目录规则。
输入：根目录与JSON清单，结构为`{"files":[{"path":"src/file.cpp","sha256":"..."}]}`。
使用：`python verify_manifest.py --root <directory> --manifest <manifest.json>`；附`--require-ascii`检查被清单覆盖的目录和文件名。
输出：验证文件数量与错误列表；成功退出0，错误退出1。脚本拒绝绝对路径、父目录跳转、反斜杠路径及指向根目录外的符号链接。
来源：现有交付包分别记录源码、压缩的设备程序、位流及对应哈希；历史程序还包含需要显式工具复现的二进制分支差异。
本项目验证：当前代码包校验通过；测试包含文件篡改和目录跳转拒绝。赛题要求目录/文件使用英文；此前中文目录的工程包须在正式提交前迁移并同步修正构建与文档路径，不能仅修改ZIP文件名。
边界：校验仅覆盖清单列出的文件，不证明未列出的文件安全或功能正确；源码与部署二进制的行为差异须另附说明，不能仅凭哈希认定算法和标定有效。
