# 外设分层排查

适用场景：I2C/SPI/UART外设、音频和打印实际输出异常。
使用：按checklist.md收集证据，再将清单与记录交给智能体分析；每次只改变一个可控因素，记录原配置和恢复方式。
来源案例：384 点宽报告的光栅分段、语音事件与资源映射、同源语音的音量对照，以及触屏和 NFC 的整机联调。
本项目效果：打印24行分条、TX排空及120ms间隔后同一纸条恢复；0%与40%音量对照确认控制有效。基线语音、触屏与 NFC 已完成整机联调，相关方法归纳为接口、传输和输出三层检查。
失效条件：针序或参考地未确认、不同电压域混接、未经审核直接写MMIO、一次更改多个变量。此清单不提供通用针脚编号，不会自动上电、复位或写寄存器。
