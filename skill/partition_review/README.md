# 软硬件划分与资源复核

适用场景：Zynq/FPGA项目在资源紧张或功能优先级变化时重新划分PL与PS职责。
输入：器件型号、各功能实时性与精度要求、实现报告、接口与时钟关系、允许变更的范围。
使用：填写prompt.md，由模型列出候选方案、保留链路、资源证据、风险及验收步骤；人员审核后只实施选定方案。
输出：职责表、可追溯的前后对照、复测清单和未验证项。
来源观察：LUT占用约一半时Slice仍可能接近满载；非核心深度计算迁往PS能够减少PL占用，但吞吐和深度精度应重新验收。
本项目验证：架构调整阶段LUT13655降至8574、BRAM41.5降至30.5；添加打印UART后的报告另列，不与旧功能阶段混作同条件对比。
失效条件：报告不对应当前位流、改变功能却仍比较同名指标、没有PS性能余量、未分析存储带宽或时钟约束。此模板不能替代Vivado重新实现。
