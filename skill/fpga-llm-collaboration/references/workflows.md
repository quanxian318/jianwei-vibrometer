# 可复制提示词

先把方括号替换成真实输入。输出需能被队友执行；没有数据时输出测量方案和缺口。

| 阶段 | 提示词 |
|---|---|
| 划分 | 「输入[算法/分辨率/帧率]、目标[板卡/时钟]、现有[基线]。给出 PS 与 PL 职责、每帧字节数、DDR 往返次数、并行级数与定点误差预算；列出保留在 PS 的理由。将估算与实测分开。」 |
| 契约 | 「根据[RTL/HLS/BD/寄存器表]和[主机代码]逐字段比对：地址单位、位宽、符号、复位值、RW/RO/W1C、启动/完成、帧尾、背压、缓存、超时。每项给证据路径，缺证据就标未知。给 5 个高价值反例。」 |
| 纠错 | 「复现是[命令/板端症状]，旧判断[原文]，新证据[日志/对照结果]。明确撤回什么结论。按可证伪性排序，并给只改一个变量的下一次测试与预期正反结果。」 |
| PPA | 「读取同器件、同工具版本的[两份实现报告]。提取 LUT/FF/BRAM/DSP/WNS/TNS；比较约束频率、目标吞吐、端到端 P50/P95。指出测量范围和输入是否可比，禁止根据 WNS 推断整机 FPS。」 |
| 验收 | 「从[源码 SHA/构建脚本/日志]产出可复现步骤，区分离线、仿真、综合、实板。逐条列原需求、验证命令、实际输出和未通过场景。不得代替原始实验记录。」 |

常用反例：负数极值和累加溢出；一拍及最后一拍；长时间背压；异步复位中断传输；DMA 启动后重入；摄像头丢帧和时间戳跳变。计时至少分别给纯算子与端到端；端到端包含需要的拷贝、DMA、同步、后处理。位精确比较同时检验输出长度、顺序和数值。
