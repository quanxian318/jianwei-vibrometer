# 对话与纠错登记

每个案例一个 ID。保留实际可见提示词和模型回答，允许对私密信息脱敏并标记位置。代码提交能证明更改发生，不能替代回答。自我纠错轨迹是公开可读的「此前说法 → 反证 → 修正 → 验证」，无需模型内部推理。

| 字段 | 填写内容 |
|---|---|
| 环境 | 板卡、工具版本、源码 SHA、产物哈希、输入编号 |
| 原始交互 | 时间、角色、提示词原文、回答原文、会话导出位置 |
| 反证 | 原始日志路径、命令、用户确认与可复现条件 |
| 公开纠错 | 旧说法、哪条证据否定它、修正方案、结果 |
| 可复用结论 | 触发条件、如何用、何时失效 |
| 状态 | 本机/仿真/实现/实板/未验证，注明是否由用户观察 |

失效示例：只找到前后提交但找不到回答时，标注「工程轨迹，缺原始回答」，并留待补录。
