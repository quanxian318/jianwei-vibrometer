# 见微｜大模型协作证据

本文件引用原会话中可见的交互和项目 Git 记录。未取得的模型回答标记为缺失。项目是 AX7010 原生 Linux + PL + Nano ESP32；以下板测记录与通用 PYNQ 示例无关。测振为主，双目是尺度与场景参考。

## C01｜双目预览与近距离失效

| 次序 | 角色与可见内容 | 对应判断 |
|---|---|---|
| 1 | 用户：「修复一下现在双目预览界面，现在左边的图是黑白的，右边的图有大量无效测量点」 | 拆开彩色预览、匹配有效率和物理尺度三个验收项。 |
| 2 | 模型提问：「目前相机镜头到散斑铝片大约多远？这会影响近处是否超出双目的搜索范围。」用户：「不到20厘米」 | 搜索范围是候选原因，仍需受控对照。 |
| 3 | 模型建议把目标放到约 30–50 cm 验证。用户：「已调整，但是20cm的时候希望也可以」 | 30–50 cm 改善不能替代 20 cm 验收。 |
| 4 | 用户：「这张图片是调整之前的，你重新接一张」 | 此截图不能用于证明调整后效果；新取证绑定距离和帧。 |
| 5 | 模型分别请求放置 20 cm、50 cm 目标，用户确认：「已放好20厘米」「散斑板，50cm已经放好」 | 具备距离对照的布置证据；本包未附原图和标定数据。 |

**纠错及验证边界。** 原截图受用户反证，不能支持调整后结论；改用按距离重新采集的证据，并把预览估计与真实测量分开。Git 提交 [a01fed8](https://github.com/quanxian318/jianwei-visual-vibrometer/commit/a01fed8) 记录同帧 BGR、扩展两段视差搜索及有效邻点规则，并报告 83 组 PL/软件模型对照无差异；同时明确未通过物理 20 cm 精度和可靠性验收。这是提交所载结果，本轮未重跑；此处没有可导出的完整模型修改答复。把这一经验转成 [纠错与验收提示词](../skill/fpga-llm-collaboration/references/workflows.md)。

## C02｜报警：命令输出与实物动作分层

- 用户：「能不能解除调整测量框之后就没办法标定的这个限制，直接按照那个标定值换算即可」
- 模型进展原文：「修改已部署。当前测量框没有对应的停机基线，程序要求先采基线。」用户确认电机停止，随后确认启动。
- 模型：「程序已输出红灯和蜂鸣器控制信号。实物红灯现在是否亮起，蜂鸣器是否间歇响？」用户：「红灯亮，蜂鸣器响」。之后用户另报告高阈值下正常状态正常。
- **提炼：** 把尺度换算的标定值和 ROI 的停机基线视为不同有效性条件。分别记录逻辑信号、用户实物观察与待测分支。这里没有把高阈值正常与低阈值报警外推为预警已验证，也没有凭用户回复推断蜂鸣器准确节拍。源码/板端复现以项目 AGENTS.md 所列板端报警资料为准。
